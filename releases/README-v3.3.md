# v3.3 — 完整性能设置面板（50 项，7 大分组）

按你的要求，把 bb native 里所有经过语义核实的性能开关一次性全部做进启动器设置面板。仅重编 classes.dex，native/AOT/签名不变，可覆盖安装。

## 7 大分组 · 50 项设置（选择即自动保存，下次启动保留）

**① 分辨率与升采样**
- 画面分辨率 preset（原生1080p / 720p / 636p / 540p推荐 / 360p最快）
- 升采样算法（关闭 / FSR3.1 / GSR2）
- 输出分辨率、RCAS 锐化开关+强度、升采样前置、场景模板位

**② 帧率与帧生成**
- FPS 上限、游戏逻辑帧率 BB_FPS、FSR3 帧生成+UI阈值
- VBlank 频率（含 0=解锁480Hz 最低延迟）、VSync、呈现模式、呈现缓冲
- 帧步进下限、pacer 侧限帧、GPU 领先帧数、提交提前量

**③ 纹理与带宽**
- 纹理质量（1/4最省 / 1/2 / 自动 / full）、各向异性、纹理预上传
- 分块纹理/上传开关、就地纹理、纹理归位

**④ 线程与CPU**
- Vulkan 录制线程、拷贝线程、绘制准备线程、异步提交、自旋等待、Vulkan 段大小

**⑤ 显存与内存**
- GC 预算+自适应、VMA 块大小、流缓冲、常量环、staging、UMA v2、Arena 重排

**⑥ GPU 优化开关**
- render pass 内拷贝提升、跳过相同拷贝、拷贝合并距离、readback 队列、管线缓存、热页跟踪、遮挡查询、Guest 显存直放、常量就地、VM 复制队列

**⑦ 着色器编译**
- 异步编译（自动/2/4线程/关）、游戏内 FPS 显示

## 已核实排除（默认即最优，做了反而更慢，源码注释有实测数据）
- BB_ASYNC_FENCES=1：79 vs 83 FPS，更慢 → 强制移除
- BB_PACE_CATCHUP=1：30 帧抖动 → 强制移除
- BB_RENDER_RES / BB_INTERNAL_W/H：DIVA boot 无分辨率 patch → 强制移除
- LSFG/MAKO 帧生成：APK 未内置模型文件 → 用内置 FSR3 帧生成替代

## 智能联动
- 勾 FSR3 帧生成时自动切 FSR3 升采样 + 缩放档（帧生成的 native 硬条件）
- 升采样关闭时强制不缩放，避免空转
