# DIVA-Launcher v4.1-Safe — 二分定位版（请优先测这一版）

## 为什么是这个版本

黑屏首次出现在 v3.8。v3.8 相对能玩的 v3.7 只改了两样东西：

1. **native so 补丁**（HonestLabels→false + GpuDirty NOP）
2. **dex 里的 d7 环境变量**（16 项）

v3.7（so 无补丁 + 老 dex）能玩；v3.8/v3.9/v4.0（so 有补丁 + 新 dex）都黑屏。我之前一直以为是补丁或某个变量，改了三次都没用。

这一版把两者**拆开**：

| 版本 | so | dex | 用途 |
|---|---|---|---|
| v3.7（已知能玩） | 无补丁 | 老 | 基准 |
| **v4.1-Safe（本版）** | **无补丁（v3.7 的）** | **新（d7 16 项）** | 测环境变量 |
| v4.0（黑屏） | 有补丁 | 新 | — |

## 判读方法（只需看一个结果）

装本版跑一次，看是否还黑屏：

- **如果能出画面、持续出帧** → 证明 d7 的 16 个环境变量**不是**黑屏原因，根因在 **so 补丁**。我下一版就只动补丁（很可能是 HonestLabels→false 这个补丁与 DIVA 不兼容）。
- **如果还是 frame 5 黑屏** → 证明根因在 **dex 的某个环境变量**。我会把 16 项再二分，定位到具体哪一个。

无论哪种结果，都能一次性排除一半可能性，不用再瞎猜。

## 附带说明

- 本版用 v3.7 的 so（无补丁），性能预计回到 v3.7 的水平（能玩但慢）。
